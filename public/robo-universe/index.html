TWO EMBODIMENTS · EIGHT FAMILIES

The complete task taxonomy

10,807 environments span single-arm Franka and dual-arm AgileX manipulation, organized into eight task families and sixteen fine-grained categories.

OVERVIEW

Scaling environments for embodied coding agents.

Foundation models can control robots by writing programs, observing the outcome, and revising their actions. Studying this capability requires diverse executable environments for both learning and held-out evaluation.

01 Environments

From real manipulation to simulation

Real robot demonstrations ground task goals and scene construction. Resettable physics environments make repeated interaction and automatic verification possible.

02 Evaluation

Measure performance on unseen tasks

RoboUniverse-Verified holds out tasks from the collection and evaluates agents through a common interface with hidden grading logic.

03 Post-training

Learn from multi-turn interaction

The collection supports trajectory generation and model post-training, with transfer studies extending beyond the source environments.

REAL2SIM CONSTRUCTION

From real demonstrations to executable tasks.

A coding agent constructs the scene, reference solution, and verifier. Independent quality checks examine source fidelity, reset-and-replay execution, and verifier robustness before packaging.

  1. 01

    Curate & specify

    Filter source demonstrations for completeness and a clear goal. Specify the objects, initial state and intended outcome while allowing alternative valid strategies.

  2. 02

    Equip the construction agent

    Provide perception tools, an asset library and physics-modeling skills covering contact geometry, mass, friction, joints and constraints.

  3. 03

    Build, render & debug

    Construct the scene, reference controller and verifier. Revise them using rendered-versus-source comparisons and physics-execution feedback.

  4. 04

    Audit & package

    Independently review source fidelity, reset-and-replay execution and verifier robustness. Return failures for revision before packaging an isolated environment.

Execution is checked after reset

An independent QA agent replays the reference controller from the initial state and checks whether it completes the intended task.

The verifier is audited independently

Checks cover source fidelity and invalid shortcuts, including penetration, teleportation and transient success states.

ROBOUNIVERSE-VERIFIED

Evaluate the full interaction loop.

An embodied coding agent receives a manipulation goal and interacts with a resettable scene. It writes executable control code, observes the resulting state, and revises its approach over multiple turns.

  1. 01

    Observe

    Inspect the task and the observations available through the environment interface.

  2. 02

    Program

    Write executable code that translates the goal into robot actions.

  3. 03

    Execute

    Run the control program in the physics simulation and receive feedback.

  4. 04

    Revise

    Use new observations to correct the plan and continue toward the goal.

AGENT INTERFACE

Observations and executable actions

The isolated, Harbor-compatible harness exposes the task interface while keeping privileged simulator state, the reference solution and grading logic hidden from the agent.

SUCCESS VERIFICATION

Check the environment outcome

Task-specific verifiers evaluate the resulting environment state. A model’s claim of completion is not itself evidence that the goal has been achieved.

COLLECTION → HELD-OUT EVALUATION

10,807 environments. A 500-task evaluation set.

The full collection spans 4,132 Franka and 6,675 AgileX environments. The current RoboUniverse-Verified evaluation uses a held-out selection of 500 tasks. Collection counts on the cards describe the complete inventory, not the number of evaluated tasks in each family.

POST-TRAINING & GENERALIZATION

From interaction trajectories to robot control.

We study supervised post-training on multi-turn robot interaction, using Qwen3.6-35B-A3B as the base model for RoboUniverse-35B-A3B. Evaluation covers held-out manipulation and transfer beyond the source collection.

  1. 01

    Collect interaction trajectories

    Generate multi-turn demonstrations with GPT-6 Astra in the training environments, recording executable actions and environment feedback.

  2. 02

    Post-train the coding agent

    Two-stage, full-parameter supervised fine-tuning adapts Qwen3.6-35B-A3B to robot control through executable programs.

  3. 03

    Evaluate generalization

    Compare the resulting model on held-out tasks and assess transfer to additional simulated environments and a physical robot.
